Garden Cafe website package

Main file: index.html

The website and its images are embedded in this single HTML file.

To publish with GitHub Pages:
1. Extract this ZIP on your device.
2. Open your GitHub repository.
3. Upload index.html to the repository root (or replace the existing index.html).
4. Commit the changes.
5. In Settings > Pages, ensure Pages is enabled for the correct branch and folder (usually main / root).
6. Open the published URL after deployment finishes.

Note: This is a prototype website. Confirm prices, service/tax, contact details, and permission to publish with Garden Cafe before making it public.
